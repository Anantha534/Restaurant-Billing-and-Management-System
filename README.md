# Restaurant Billing and Management System

A web application that allows restaurant staff (Admin) to manage the menu, tables, and orders, while customers can browse the menu, place orders, and view billing history.

## Current Progress
- Repository initialized
- Frontend project structure setup
- HTML/CSS/JavaScript environment configured
- DOM event handling practice completed
- Counter functionality implemented
